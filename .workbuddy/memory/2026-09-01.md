## 率土官网 my-army 账号数据抓取（stbj.163.com）
- 用户目标：抓取自己账号的武将/战法信息（stbj.163.com/my-army 页面，实际是 iframe 嵌入）。
- 技术路径（踩坑记录，可复用）：
  1. 页面是 SPA + iframe（src=stbj.163.com/old-entry/my-army），数据接口在 `sm-g10-15fzm7ns-prod-ws.nie.netease.com:12104`（WebSocket 服务器，gameid=g10）。
  2. 接口鉴权：`Authorization: <JWT>` + `?aid=<网易通行证>`。GetUser/GetLayout/GetMyOrg 用浏览器 cURL 的 token 可调；GetMyHero 等 40011（token 非通用，需页面内 JS 的 localStorage token）。
  3. CORS：父页面(stbj)直接 fetch sm-g10 被跨域拦截；iframe 内 fetch 同域可通。
  4. **最终可行方案**：用户朋友提供的 console 脚本——在 iframe 上下文执行，相对路径 /api/ngsocial/Reader/HandleGameProxy POST {cmd:community_query_user_info}，自动读 localStorage token，结果下载为 json。
- 成果：`D:\Desktop\账号数据.json`（原始，含 token 敏感字段，勿外传）；解析落盘 `D:\Desktop\shandou\账号武将库_解析.json`。
- 解析结果：赛季 2001；武将 59 个（57 映射 hero_extra，2 未知 id 110412/110413 需查）；战法 87 个（含谋攻/突击等基础 + 高级）。字段语义：hero 行[1]=进阶红度(0-4满红)、行[9]=觉醒、行[11]=等级；skill 行[1]=等级。
- 满红武将 8：朱儁/曹操/刘备/华雄/张飞/黄盖/山涛/向秀；已觉醒 6：王美人/皇甫嵩/周泰/凌统/山涛/向秀。
