## 目录结构
- `抖音/`：原始视频（含 `开荒/` 子目录）
- `抖音_frames/`：抽帧插图素材（每视频一个子目录，含 `_meta.txt` 元信息）
- `资料库/extract_frames.py`：递归抽帧脚本
- `资料库/gen_one.py`：单份 Word 生成脚本（读 content JSON → 渲染 docx）
- `资料库/video_index.md`：56 视频索引、分类、状态
- `学习汇报/`：最终 Word 输出（51 个 .docx）
