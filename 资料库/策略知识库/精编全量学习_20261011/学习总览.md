## 后续配将采用的判断顺序

1. **锁本次任务和账号。** 先分主力、抗线、翻地、拆迁、开荒与过渡任务；确认本次赛季、剧本、精确武将版本、研究与宝物。旧账号、旧表和历史案例只作待验线索。
2. **画清成立条件。** 输出由什么事件供给，控制先于谁行动，伤害能否到达合法目标，保护覆盖哪个威胁，恢复什么时候开始，最后靠谁收口。缺少一环先否决或记为过渡方案。
3. **算全账号资源。** 优先比较前三主队的完整程度；逐项计算稀缺将法让给另一队后的损失。已有可用、新获取可行、空闲数、总份数分别记录；明确保留的旧队继续占用。
4. **逐效果检查。** 战法类型、具体效果、对象、触发、时长及释放顺序都要匹配。同类同效果规则、状态不可叠加、触发竞争和功能冗余分开处理。
5. **落实速度、距离与养成。** 使用真实最终面板和装备文本。速度服务于某项职责；普通攻击距离、主动战法距离、子战法有效距离、实际兵系不能互相替代。
6. **用事件战报反馈。** 先找最早断掉的环节，再改动。摘要战报只统计结果；概率或强度调整按项目规则取得每队至少5份代表事件战报。完整事件链与当前文本已确认的确定性硬错误，可直接修正。

账号导出只提供空闲战法数时，总份数按项目资料推定并注明来源，不能把推定当实测。版本按精确武将ID和自带战法连接主库；`hero_extra.quality=4-SR`不是四星。按后续明确规则解释“极”为觉醒；旧“满红”措辞不覆盖后续规则。XP是标签，不单独决定新获取阶段。

## 报告间的认识如何合并

### 队伍数量取决于净收益

005、007、026、055、057讨论三队、两队或四队，并不互相否定。任务不同、稀缺战法不同、第三队贡献不同，结论就会变化。可以降低未成型主力投入，同时保留低成本功能队；比较时既算主队增益，也算失去翻地、抗线、拆迁能力的代价。

缺核心并不是所有替代都无效。009、042、056要求先列缺失职责：甄洛补恢复不能自动补张机前期减伤，貂蝉控制不能自动补孙权解控。替代方案必须说明保住了什么、损失了什么。

### 防守组合要算净保护与触发损失

022、023中的孙权与张机不是文本上的硬禁配。规避会减少受伤恢复的入口，却也减少兵损，并保留解控和空窗兜底价值。比较同队或拆队应看全账号净收益。

孟获、垒实、百战都需要适当承伤，但入口不同：孟获统计自身受伤；垒实恢复、自净和规避看受到普攻，援护另外看位置与回合开始；百战看消层恢复与出伤补层。多承伤可能更早击穿，过度保护也可能减少成长或恢复入口。不能只看恢复总量。

021、033中的长期防守仍要有后段收口。战必限制普攻，磐阵接部分首伤并提供规避，二者不能包办输出、恢复和全部控制。战必虽不直接给追击施加独立限制，却可切断依赖普攻的追击前提。

### 输出体系由具体事件定义

| 机制 | 应记录的入口 | 常见误计 |
|---|---|---|
| 攻其不备（035、036、041） | 对有效目标造成攻击伤害，后续易伤可以服务策略伤害 | 策略伤害也供叠层；不同目标合计层数 |
| 神兵、大赏（050、051、059） | 前期敌方受伤端、友方造成端，以及实际命中和覆盖 | 增幅代替伤害来源；把不同配置算例拼在一起 |
| 百战（048） | 开局层数、回合与受伤消层、造成伤害补层 | 三层减伤常驻；个人耐久等于全队保护 |
| 杜预、贾充（043、044） | 成功发动后的追加、实际受伤与恢复后的概率响应 | 主动尝试等于成功；一伤固定多次群奶 |
| 魏弓贾诩（065） | 每回合首次主动尝试，以及每个人各自的低兵力条件 | 所有主动每次都触发；全队必须一起低兵 |
| 高顺群骑（064） | 首次阈值、下一次行动、即时清状态与逐笔增益 | 队友永久洞察；148个百分点直接当最终倍率 |
| 马岱（067） | 队友先供触发，马岱后续伤害消费及保护 | 裸速抄顺序；连击分兵重复消费同一个下一次增益 |

这些是报告与保存文本的学习模型。奉令、登锋等保存描述存在旧新拼接，实际使用先过[待复核清单](待复核与使用边界.md)，不能把模型当当前参数证明。

### 速度与距离都不是越多越好

028、046强调先手控制、先解控或先供增益；067强调队友先供触发、马岱后行动。需要的是最终队内顺序和时窗，没有全项目通用速度线。张机金匮按受伤概率恢复，不能凭这个自带推导“张机必须比主C快”。

037、040、054、063区分普攻距离与战法有效距离。增距可能解决普攻够不到、补追击入口，也可能扩大目标池，破坏定点输出，或打到受击获得洞察的敌人。单看相同距离不能保证集火。

### 养成和内政采用条件收益

010、014、015、025、058、062要求明确任职、城池、征兵、拆城与阶段条件。税收、分城产量、预备兵、征兵耗费是不同账目；历史产量或单次金币不能直接当当前保底。宝物基础属性、概率词条、真实攻击机会和机会成本分开算，不能换算成“几红”。四星、碰瓷和过渡也有觉醒、经验、征兵与材料成本。
