## 一、配将的固定检查顺序

每次给出队伍前，按以下顺序核对；任一项缺少当前证据，就在结论中明确写出，而不是补猜。

1. **资产与版本**：同名武将必须以完整卡面和自带战法锁定版本；确认星级、觉醒、已占用队伍与是否允许拆解。读取原始武将配置时，`book_type != 0` 不是可上阵武将，`is_release` 也不能单独作为“已实装/可获取”的判断依据。
2. **位置与职责**：队伍应有大营、中军、前锋三个位；大营生存是胜负底线。明确每人的输出、承伤、控制、恢复或辅助职责。
3. **COST**：三名武将总 COST 必须不超过当前可用上限；上限数字只取本次账号/客户端证据。
4. **攻击距离与站位**：核对武将普攻攻击距离是否够到应攻击的目标；存在援护、挑衅等强制选目标状态时，另按当前文本和战报核对实际落点，不能只看静态距离。
5. **战法距离**：逐个核对战法有效距离、目标与兵种限制；不要把武将攻击距离当成普通战法的有效距离。
6. **发动逻辑**：按当前描述区分指挥、主动、被动、追击及特殊类型；追击战法尤其要检查是否依赖普攻命中与体系条件。控制链要按前提拆开：犹豫只阻止主动战法；怯战使普攻无法发生，依赖普攻命中的追击也就没有触发前提。不得把“封主动”误判为同时克制追击体系。
7. **效果冲突**：按《战法冲突判定规则》排查同类相同效果的数值替换或不可叠加；具体战法是否属于相同效果、是否带有独立副效果，须读取当前文本后判定。
8. **属性与兵力关联**：伤害、恢复、速度、攻城等效果要与战法标明的属性关联和实际兵力条件匹配。未分配属性的基础显示层可按 `(初始值 + 成长 × (等级−1)) ÷ 100` 复算；设施、同阵营、称号、兵种、兵种特性等修正必须另行叠加，不能擅自套用单一总公式。
9. **队内协同**：检查阵营、称号、兵种、速度顺序及先后手目标是否形成实际收益，而非只看单卡强度。兵种特性须以“兵种类型/特性 ID + 当前文本”判定，不能只按同名特性套效果。
10. **全局资源合法性**：同一武将不能重复上队；同一战法的可学习数量、拆解来源、觉醒材料和已占用战法必须全局核算。

涉及输出或恢复时，还要执行玩家实测参考中的补充检查：逐效果拆解战法、识别增减伤通道、确认属性影响与状态快照时点，并将历史公式系数降级为验算参考。

战法冲突按 [战法冲突判定规则_20260901.md](战法冲突判定规则_20260901.md) 执行：同类相同的持续性效果和属性增减按数值替换；同类相同的增益、减益、控制按后释放者失效；分兵、连击、规避等状态不可叠加。具体战法是否构成“相同效果”、是否有独立副效果，仍须逐条读取其当前文本。

安装包手册仅能印证“同类型同种效果不可叠加”的总方向，不能覆盖或降级上述已确认细则。组合战法由多个状态效果 ID 构成，冲突必须拆到单个效果判断；本地补充库可查 206 个效果 ID。

## 二、账号诊断的固定检查

- 自带战法位、觉醒后战法位、已学习战法和空闲卡要分开统计。
- 拆解一张卡前，先检查它是否为唯一版本、5 星觉醒材料、主力队核心或其他队已占用资源。
- 多队方案先保证主力队的完整性，再安排碰瓷、铺路、攻城、开荒或二线队；不以凑满队数为目标。
- 速度问题要分别看行军和战斗先后手；具体阈值、宝物、赛季加成和实战效果以当期客户端/战报为准。

## 三、可以稳定采用与必须复核的边界

| 可以作为结构规则 | 必须重新核对 |
|---|---|
| 三阵位、COST 约束、距离与站位需分别核对、战法有发动类别、战法学习数是全局资源、同名武将可能有不同版本 | 武将/战法数值、发动率、目标数、距离数值、COST、星级、属性成长、觉醒条件、拆解/研究材料、兵种和称号加成 |
| 阵营/称号/兵种/速度会影响队内协同，发育与地图存在资源和路径约束 | 土地守军、开荒兵力阈值、资源与时间、建筑等级、施政、宝物、赛季剧本、当前强度与推荐队伍 |
| 原始配置中的武将 `book_type`、战法类别的文字定义、状态效果 ID 和组合战法由多个效果 ID 构成 | 士气系数、伤害总公式、所有属性加成的加算/乘算顺序、`is_release` 的可用性含义、未完成映射的数值编码 |

## 五、来源精简规则

- 原文件保留在 `AA率土`；资料库只保留能直接参与判断的规则、字段边界和冲突登记，不复制整篇手册。
- 同一规则只维护一处主条目，以链接指向原始文件或结构化数据；不再生成“全文摘录 + 核验报告 + 备份”三份副本。
- 新资料先比对现有主条目：能补一条规则就补原条目；只有形成独立、可复用的数据结构或冲突清单时才新增文件。

## 六、结论表达模板

给用户的配将或诊断结论应按证据强度分层：

- **已核实**：本次账号截图、当前客户端文本或当期官方资料可直接证明。
- **结构判断**：依照本规则得出的搭配逻辑，需写清前提。
- **待复核**：当前版本数值、某一战法的具体效果归类、赛季/施政/宝物规则等未有当期证据的内容；不得写成确定结论。

## 七、已知空白

本机制库不覆盖施政、宝物、当前赛季剧本、征服赛季内容与现代武将/战法参数。遇到这些主题，应另查当前官方或请用户提供游戏内截图。

## 八、赛季选择时的核对方法

由2026-09-05整理的《一分钟了解率土之滨玩家要经历的赛季和试师赛季征服赛季》案例补充。下述方法可用于咨询；作者推荐仅作为历史案例，不视为官方机制。

- 先查账号实际赛季阶段、备战区可报名入口和角色标签，再查目标剧本的报名限制、匹配条件及特殊玩法。不能只用“S赛季/征服”简称推断对手强度与可用内容。
- 选择剧本时比较账号卡池、进阶情况、能投入的时间以及同盟安排，再判断剧本的特殊规则是否适合账号。单一视频的“适合新手”不能替代这些条件。
- 案例作者提到试师入口与新锐标签，并推荐百业争鸣用于较平稳的养号体验、北伐兴汉供卡池较多但进阶较少的玩家考虑。这是其当时的建议，不保证报名入口、匹配保护或环境在当前仍相同。
- “征服遍地满红”“萌新不能进入”“固定两个月结束新手期”等说法不能据本案例写成硬规则。抽卡活动、跑区、服务器名称及旧奖励参数没有纳入机制库。

核验记录：原转写定位作者建议，00:43字幕确认推荐试师本；00:51原画面可见北伐兴汉相关入口。旧逐帧版把部分剧本与字幕时间记错，时间表不作为机制依据。后续具体选本时，以当次游戏报名界面和官方当期说明确认事实。
