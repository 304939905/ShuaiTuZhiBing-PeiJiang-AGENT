# 战报阅读与配将反馈规则

> 建立日期：2026-09-21  
> 目标：把战报作为配将结果的主要检验途径，定位“最早出现的机制偏差”，而不是只统计胜负或总伤害。  
> 依据：12篇玩家文章与现有机制库的第二轮交叉复核；其中既有相互支持的结构，也有单篇实验和同源复述。具体证据等级见玩家实测机制参考，当前数值仍以客户端与本次战报为准。

## 一、战报证据是否足够

一份可做深度复盘的战报，优先包含：

1. 双方阵容、位置、武将版本、等级/兵力、携带战法与宝物。
2. 准备回合完整日志，用于识别指挥/被动效果、速度和初始状态。
3. 正式回合逐回合日志，至少覆盖首次异常发生前后。
4. 伤害与恢复统计页，用于核对主伤害源、实际承伤和治疗是否与过程一致。
5. 若要精确验算，补充关键时点的兵力、属性变化、增减伤状态、控制状态和兵种。

证据分级：

| 等级 | 定义 | 可以得出的结论 |
|---|---|---|
| `complete` | 阵容页、准备回合、关键正式回合和统计页完整 | 可定位事件链；结合当前战法文本可确认确定性配置错误。 |
| `partial` | 缺少部分页面，但关键异常前后可见 | 可提出高概率原因，不能做精确公式验算。 |
| `summary_only` | 只有胜负、总伤害或零散截图 | 只能登记结果，不解释机制，不据此改队。 |

不可读、被裁切或缺失的字段必须写“未知”，不能用常识补齐。

## 二、固定阅读顺序

### 第1步：确认战斗前提

- 锁定双方三阵位、武将版本和自带战法，防止同名版本混淆。
- 记录实际携带战法、兵种、宝物、初始兵力和已知加点。
- 记录赛季、士气、土地/玩家战斗、是否存在特殊剧本或设施效果；看不到就标未知。
- 先判断这份战报是否具有代表性：正常兵力、正常配置、常见对手，而不是残兵、明显等级差或特殊事件战斗。
- 若存在援护、挑衅等强制选目标状态，单独记录其施加与移除时点；不能只用静态攻击距离推断普攻最终落点。

### 第2步：建立准备回合账本

按日志顺序记录：

- 指挥/被动战法何时施加；
- 谁先获得先攻、洞察、连击、规避、增减伤和属性变化；
- 是否出现同类相同效果被替换或后释放失效；
- 实际速度顺序是否符合配将预期；
- 持续伤害、休整、持续型急救等状态在什么属性/兵力条件下被施加。

这一步决定后续正式回合里哪些效果实际存在，不能从结果页倒推。

### 第3步：按“行动链”阅读正式回合

对每名武将依次检查：

```text
回合开始状态
→ 行动前控制/持续效果
→ 是否能试图发动主动战法
→ 主动战法是否发动、目标是否合法
→ 是否能发动普通攻击
→ 普攻目标、分兵/反击
→ 追击战法是否具备触发前提
→ 回合末状态移除或持续结算
```

不要把“没造成伤害”直接写成“战法没发动”。它可能是未尝试、未发动、目标无效、被规避、伤害被压低或状态冲突。

### 第4步：找出第一个异常事件

复盘重点不是最后一回合，而是**实际战斗首次偏离配将预期的位置**。例如：

- 预期我方先手，实际敌方先控制；
- 预期追击输出，但普攻被怯战阻断；
- 预期某增益覆盖主输出，实际目标选择错误；
- 预期两项效果叠加，准备回合已提示后者失效；
- 预期治疗抬血，但先被围困或没有足够伤兵；
- 大营在前三回合先被集中攻击，后续输出不足只是结果而非根因。

后续诊断和改队建议必须围绕第一个异常事件展开。

## 三、伤害与恢复的核对方法

### 1. 伤害

先确认：伤害类型、施加者兵力、目标受击前剩余兵力、伤害率是否受属性影响、双方关键属性、有效增减伤、无视属性和兵种相克。

- 用“三部分伤害结构”解释方向：兵力基础 + 属性基础 + 主要伤害。
- 普通物理伤害存在随机波动，数点或小幅差异不能证明机制异常。
- 单次显示伤害受目标剩余兵力封顶；残兵目标上的低伤害不能用于反推完整伤害能力。
- 策略战法不能只比较面板伤害率；还要看谋略、历史增长率结构、目标谋略、目标数和发动次数。
- 增减伤先按战法冲突规则排除失效状态，再按“造成/受到、物理/策略、普攻/主动/追击”分通道分析。
- 2022年“受到策略伤害降低不能完整抵消造成策略伤害提高”的结论是版本敏感假说。只有当前战报出现同类现象时才进入复核，不能预设它仍然存在。
- 若要判断“普通攻击伤害提高/降低”是否覆盖分兵或反击，须分别定位三类伤害事件；旧文章支持会覆盖，但不能只凭旧术语替当前版本下结论。

历史公式的用途仅限于：判断数量级是否异常、比较改动方向、为可控复现设计变量。不得用旧系数把几百点误差包装成当前精确结论。

### 2. 恢复

依次检查：

1. 目标当时是否有伤兵；
2. 是否处于围困/禁疗；
3. 恢复属于即时、休整还是持续型急救；
4. 同时记录恢复状态施加时与实际结算时的兵力、谋略；2022年文章支持状态类恢复采用施加时快照，但这在本组材料中没有独立复现，新战法或改版后不可预设；
5. 是否存在恢复提高、属性变化、冲突覆盖或目标选择问题；
6. 实际恢复是否受目标当前可恢复伤兵上限截断。

## 四、标准诊断类别

结构化战报优先使用以下类别，避免“输出低”“打不过”这种无法执行的标签：

| 类别 | 要回答的问题 |
|---|---|
| 行动顺序 | 实际速度与预期是否一致，偏差从何而来？ |
| 触发前提 | 主动、普攻、追击或条件技为什么没有进入触发链？ |
| 目标或距离 | 站位、攻击距离、战法距离、目标筛选是否使效果落空？ |
| 战法冲突 | 哪个具体效果被替换/失效，其他副效果是否仍生效？ |
| 控制链 | 首个控制是谁施加，是否真正阻断我方核心动作？ |
| 增减伤通道 | 存活的效果分别属于哪个计算通道，有无过度堆叠？ |
| 输出结构 | 低伤害来自发动期望、兵力、属性、伤害率、目标或减伤中的哪一项？ |
| 生存保护 | 爆头或高损来自目标集中、保护缺失、控制失败还是属性短板？ |
| 恢复链 | 伤兵、禁疗、快照、目标、冲突中的哪一步使恢复不足？ |
| 兵种相克 | 具体高级兵种关系是否影响本场伤害？ |
| 兵力衰减 | 输出/恢复随兵力下降是否是主要原因？ |
| 随机波动 | 是否只是发动率、目标选择或普通物理伤害随机性？ |

## 五、什么时候可以调整配将

不能把所有问题都机械套用“五份战报”：

- **确定性硬错误**：完整战报已显示目标/距离不合法、触发前提不存在、战法冲突失效或行动顺序与硬性设计相反，并已核对当前战法文本。可以立即纠正该错误，但不能借此重做整队。
- **可控机制复现**：保持其他变量接近，至少两次复现同一机制异常，可升级为高可信机制结论。
- **随机性或强度问题**：发动率、选目标、普通物理波动、一般输出/生存评价，至少5份同队代表战报，建议5—10份并覆盖主要对手。
- **特定克制关系**：按对手类型分别统计；不能用打爆头队的失败证明队伍对所有阵容都弱。
- **改动后复验**：只改一个主要变量，重新收集战报；否则无法知道提升来自哪项修改。

## 六、战报结论的标准写法

每份深度复盘至少输出：

1. **已见事实**：战报中能直接定位的事件、回合、武将和战法。
2. **第一个异常事件**：首次偏离预期的位置。
3. **机制判断**：对应的触发、冲突、目标、伤害或恢复规则。
4. **替代解释**：尚未排除的其他原因。
5. **对配将的影响**：立即修硬错误、继续收样本，或暂不调整。
6. **下次验证项**：需要补哪一页战报、当前战法文本或哪组对照样本。

胜负、总伤害和“谁输出最高”只能作为结果摘要，不能替代以上过程证据。
