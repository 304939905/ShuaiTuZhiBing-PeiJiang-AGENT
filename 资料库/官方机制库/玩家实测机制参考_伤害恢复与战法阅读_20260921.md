# 玩家实测机制参考：伤害、恢复与战法阅读

> 整理日期：2026-09-21  
> 来源等级：**B（高传播度玩家的战报/演武实测）**，不是官方公开公式。  
> 适用方式：用于理解机制结构、发现配将风险和解释战报；具体武将/战法参数、旧版本异常和精确伤害值仍以当前客户端、当期公告及本次战报为准。

战报应用方法见：[战报阅读与配将反馈规则_20260921.md](战报阅读与配将反馈规则_20260921.md)。

## 一、配将时可直接采用的结构认识

### 1. 战法必须拆成“动作/效果”阅读

- 被动、指挥、主动、追击首先决定释放时点，不直接代表强弱。
- 一个战法可包含多个动作，每个动作可能有不同的有效距离、目标范围和生效条件。面板上显示的单个“距离/目标”不能替代逐效果检查。
- 主动战法在武将普攻前尝试发动；追击战法以成功发动普攻为前提。混乱/犹豫、怯战、洞察对两类体系的影响必须按实际前提区分。
- “试图发动”与“成功发动”不是同一事件；读取触发型战法时必须确认它监听的是哪一种事件。
- 2022年原文把“战斗开始后”解释为包含准备回合与正式回合，把“正式回合开始后”解释为不含准备回合；把“行动时/行动前”均定位在主动战法尝试之前。它们适合帮助定位日志时点，但新战法仍以当前文本和战报顺序为准。
- 原文认为：未受混乱/犹豫阻断（或因洞察免疫影响）时，每个已学习主动战法会分别进入“试图发动”判断；每次普通攻击后，各追击战法再分别检查自己的触发前提。不能把其中一个战法未发动外推为整条行动链未发生。
- “持续X回合”的移除时点并不统一，有的在武将行动前移除，有的在回合结束时移除，不能只凭字面类推。
- 攻击距离与战法距离相互独立。原文还指出援护/挑衅会改变普通攻击的通常选目标过程；遇到强制选目标状态时，应直接按战报落点复核，不能只用静态距离表判断。

### 2. 战法面板伤害率不能单独用于比较输出

- 物理和策略伤害都不是单一的“伤害率 × 属性”，而由兵力相关部分、属性相关部分和主要伤害共同构成。
- 兵力、战法伤害率/发动期望、攻击或谋略、目标防御或谋略、增减伤、无视属性、兵种相克都会影响结果。
- 大多数策略伤害的伤害率会随谋略提高；部分策略伤害和大多数物理伤害率不随属性提高。必须读取当前文本中的“受某属性影响”，不能只比较面板百分比。
- 同一基础伤害率的战法，若属性成长系数、发动次数、目标数、伤害类型或生效回合不同，实际输出可能差异很大。

### 3. 伤害可以分为三部分理解

| 类型 | 结构 | 配将含义 |
|---|---|---|
| 物理伤害 | 兵力基础伤害 + 攻击基础伤害 + 主要伤害 | 攻击、防御、兵力、伤害率、增减伤与无视防御共同决定；普通物理伤害存在随机波动。 |
| 策略伤害 | 兵力基础伤害 + 谋略基础伤害 + 主要伤害 | 施法者谋略主要影响伤害率/谋略基础部分，目标谋略形成防护；不能简单等同于“双方谋略差”。 |
| 持续伤害 | 动摇、燃烧、恐慌、妖术等有自己的分项系数 | 不能拿同面板伤害率的即时伤害直接类比；具体系数属于历史实测参数。 |

由此得到的实用规则：

- 低兵力不等于伤害必然接近零，因为属性基础伤害仍可能存在；但兵力下降仍会削弱主要伤害。
- 伤害率翻倍不保证最终伤害翻倍，因为兵力基础伤害不一定随伤害率变化。
- 单次伤害不会超过目标受击前的剩余兵力；目标残兵造成的伤害截断不能反过来证明伤害公式、增减伤或输出能力发生异常。
- 攻击与防御的收益、目标谋略的减伤收益都不是全区间线性；高低区间可能出现边际收益变化。
- 配将时可以用“输出战法/发动期望 × 增伤 × 属性影响”比较构建方向，但它是结构化近似，不是单次伤害的完整公式。
- 原文把“普通攻击造成的伤害提高/降低”解释为同时影响普通攻击、分兵和反击。这条属于历史术语实现，分析当前战报时应把三类伤害分别核对，而不是默认只影响主普攻伤害。

### 4. 恢复效果的关键时点

- 恢复值至少受施加者兵力、恢复率和恢复提高效果影响；标注“受谋略属性影响”的恢复率还受施加者谋略影响。
- 对休整、持续型急救等状态类恢复，原文实测结论是：相关变量在**状态被施加时**取值，而不一定在每次恢复真正发生时重新读取。
- 因此，恢复武将的速度、施加恢复状态前是否已获得谋略/兵力相关增益，可能影响后续多回合恢复。遇到新战法或改版战法时仍需战报确认是否沿用该快照逻辑。
- 围困/禁疗、伤兵是否充足会限制实际恢复值；公式值不等于一定能恢复出的兵力。

### 5. 等级不是独立伤害变量（历史实测结论）

2022年的跨等级战报验算支持：等级通过兵力上限和属性间接影响伤害，没有观察到“等级差大于10级便额外增伤”的独立系数。当前咨询中不得以“等级压制”直接加减强度；若当前客户端出现明确规则或反例战报，再更新此结论。

### 6. 兵种相克要按具体高级兵种关系核对

- 兵种相克表现为减伤：“A克制B”表示B攻击A时受到相克减伤。
- 基础关系的历史参数为骑克步30%、步克弓25%、弓克骑20%；这些数值用于解释旧战报，当前精确计算仍需核对当期文本/战报。
- 高级兵种并不总能由基础三角关系推导。历史文章列出的常见例外包括长枪兵、弓骑兵、弩兵、重骑兵的增强或反转关系。
- 原文的235项全表只有关系、没有具体减伤值，且会明显增加资料库体积；本库不抄录全表。实战涉及某一高级兵种对局时，再查该具体组合。

## 二、历史实测公式（只作结构与验算参考）

以下系数来自2021—2022年的玩家战报/演武归纳。它们能够解释文章所用战报，但**未经当前版本重新标定**，不得直接作为当前伤害计算器的权威参数。

记：

- `B` = 造成效果者当前兵力；
- `R` = 战法伤害率或恢复率（小数形式）；
- `D` = 历史基础模型中的有效增减伤系数；单一通道时写作 `max(10%, 1 + 有效增减伤总和)`。“有效”表示已经先按《战法冲突判定规则》排除被替换或失效的效果。策略增减伤若出现本文件第三节所述分通道现象，不能再把所有效果压成一个 `D`；
- `A` = 攻击属性；`I` = 谋略属性。

历史物理伤害模型：

```text
物理伤害 = 兵力基础伤害 + 攻击基础伤害 + 主要伤害
普通兵力基础伤害 ≈ 373 × B / (7700 + B)
动摇兵力基础伤害 = 普通兵力基础伤害 / 3
普通攻击基础伤害 = A × 随机数(0.30~0.39，步长0.01) × R × D
动摇攻击基础伤害 = A × 0.4 × R × D
主要伤害 = 300 × B / (3500 + B) × R × D × 攻防影响
有效攻防差 = A - 目标防御 × (1 - 无视防御总和)
攻防影响 = 3 - 500 / (250 + 有效攻防差)，当有效攻防差 ≥ 0
攻防影响 = 100 / (100 - 有效攻防差)，当有效攻防差 < 0
```

历史策略伤害模型：

```text
策略伤害 = 兵力基础伤害 + 谋略基础伤害 + 主要伤害
普通/火攻兵力基础伤害 ≈ 178 × B / (6459 + B)
燃烧/恐慌/妖术兵力基础伤害 = 普通策略兵力基础伤害 / 3
普通/火攻谋略基础伤害 = I × 0.5 × D × 目标谋略影响
燃烧/恐慌/妖术谋略基础伤害 = I × 0.25 × D × 目标谋略影响
主要伤害 = 300 × B / (3500 + B) × R × D × 目标谋略影响
有效目标谋略 = 目标谋略 × (1 - 无视谋略总和)
目标谋略影响 = 1，当有效目标谋略 < 50
目标谋略影响 = 1 - (75 - 9375 / (75 + [有效目标谋略])) / 100，当有效目标谋略 ≥ 50
```

原公式图片使用了 `[有效目标谋略]` 记号，但正文没有单独解释该方括号究竟表示整数化还是仅用于分组，因此本库不自行补定义。两条影响函数补全了原精编条目此前遗漏的分段项；如需逐点精算，应同时使用原文给出的离散阈值或重新做当前版本对照实验。它们仍只是历史验算公式，不自动代表当前版本。

历史属性影响模型：

```text
实际伤害率 = 基础伤害率 + 伤害率增长率 × (谋略 - 80)
实际恢复率 = 基础恢复率 + 恢复率增长率 × (谋略 - 80)
恢复值 = 300 × B / (3500 + B) × 实际恢复率 × (1 + 恢复提高效果总和)
```

原文称受属性影响的伤害率/恢复率会取整到1%的整数倍，采用“八舍九入”。这属于历史实测取整规则；需要做精确战报验算时再核对当前版本。

## 三、策略增减伤通道：高价值但必须复核

2022年的一篇主实验文章提出：策略伤害的增减伤并非全部放进同一个加减池，而要区分效果的作用方向。另一篇文章主要使用同一作者提供的战报与测试结果做解释和扩展，**不属于第二次独立复现**。

| 历史实测通道 | 文章中的典型例子 | 当时观察 |
|---|---|---|
| 目标“受到的策略伤害提高/降低” | 神兵天降、避其锋芒、磐阵善守、步步为营 | 同方向相互抵消。 |
| 攻击方“造成的策略伤害提高/降低” | 大赏三军、无心恋战 | 同方向相互抵消。 |
| 两个方向交叉 | 大赏三军 vs 磐阵善守/步步为营 | 文章实测不能完整相互抵消，导致“受到策略伤害降低”超过其对应通道后收益溢出。 |

这组结论在文章中被作者称为“严重缺陷”，因此它可能是实现缺陷而不是永恒规则，也最可能被后续版本修复。使用约束：

1. 配将时先把增减伤按“造成/受到、物理/策略、普攻/主动/追击”等精确文本分通道，不得把所有百分比机械相加。
2. 先处理战法冲突，再计算不同来源中实际保留下来的增减伤；“冲突/覆盖”与“伤害计算通道”是两个阶段，不能混为一谈。
3. 可以据此提出“同一减伤通道可能过度堆叠”的风险，但不能仅凭旧文章断言当前队伍一定溢出。
4. 若该判断会改变主力队的战法取舍，必须用当前战法文本和至少一份可控战报复核。
5. 文中的“某武将不值得用”“某队强”的推荐只属于作者当时环境观点，不进入机制库。

## 四、用于配将与账号诊断的检查补丁

在基础十步检查之外，涉及输出/恢复时追加：

1. **逐效果拆战法**：分类、释放/触发时点、距离、目标、伤害类型、持续类型、属性影响分别记录。
2. **读当前文本**：确认“受属性影响”的具体属性；没有该字样时，不自行推断伤害率随属性变化。
3. **比较完整输出期望**：同时看发动率、准备回合、次数、目标数、伤害类型、可行动性与队友提供的控制/增伤，不以面板伤害率排序。
4. **识别增减伤通道**：区分“造成/受到”和物理/策略/普攻/主动/追击；再做冲突、覆盖和收益分析。
5. **识别快照时点**：持续伤害、休整、持续型急救等状态需要检查施加时属性和后续生效时属性，不能默认实时更新。
6. **精确数值降级**：老文章的公式系数、兵种减伤百分比和战法参数只用于解释历史战报；当前推荐仍以本地当前数据库、客户端截图和战报为准。

## 五、第二轮相互印证结果

| 机制结论 | 12篇文章内部证据 | 与现有资料库/规则库的关系 | 最终使用级别 |
|---|---|---|---|
| 战法须按类型、时点、动作、目标、距离和触发前提拆读 | 《读懂战法》系统说明；伤害、恢复文章分别展示按效果拆解的必要性 | 与基础机制库的距离、类型、冲突逐效果判断一致 | **结构规则**；具体术语仍看当前文本与日志 |
| 物理/策略伤害由兵力基础、属性基础、主要伤害三部分构成 | 总篇提出结构；物理篇、策略篇给出完整公式；独立战报用一个物理样本验算 | 与战报规则中的“不能只看伤害率和总伤害”一致 | **高价值历史模型**；系数不是当前官方参数 |
| 策略战法存在“基础伤害率 + 属性增长率” | 总篇、策略篇、专项文章三处一致，但主要来自同一作者体系 | 现有规则已要求读取“受谋略影响”，本次补足完整分段公式 | **结构可用，专属增长率降级** |
| 状态类恢复在施加时读取兵力/属性 | 仅《恢复效果》一篇明确给出，12篇中没有独立复现实验 | 现有战报规则已要求检查施加时点，但此前容易写得过于确定 | **待当前战报复核的历史快照结论** |
| 策略增减伤可能分“造成/受到”通道 | 一篇主实验 + 一篇基于同批证据的注解，不是两个独立实验 | 与冲突规则不矛盾：先判效果是否冲突，再判保留下来的效果进入哪个计算通道 | **版本敏感假说**；改变主力配置前必须复现 |
| 不存在无条件的“等级差大于10额外增伤” | 等级文章用跨等级战报代入旧公式；伤害公式体系可解释样本 | 与基础库“等级通过属性和兵力间接影响”方向一致 | **历史反例**；表述为“未观察到”，不升级为官方声明 |
| 高级兵种关系不能完全按骑步弓三角类推 | 兵种文章给235项表；《读懂武将》重复该结论，但同作者且未给独立数据源 | 与现有规则“具体高级兵种逐项核对”一致 | **查询提醒**；具体关系、数值需当前证据 |
| 单场公式验算可以检查数量级，不能证明普遍强度 | 独立文章验算一个马超普攻样本，作者也说明曾多次漏项后才算对 | 与战报规则的证据分级、单变量复验一致 | **方法示例**，不是公式的独立充分证明 |

第二轮复核后，没有发现需要推翻现有战法冲突规则的内容。两套规则处理的阶段不同：冲突规则决定某个效果是否存在；伤害模型只计算仍然有效的效果如何影响数值。
