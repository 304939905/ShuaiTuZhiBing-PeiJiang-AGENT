# 率土之滨 配将师 —— 账号数据抓取教程

> 用途：把某个账号的「拥有武将（含红度）、战法、宝物」抓下来，供配将师做个性化配将。
> 切换账号 = 重新登录新账号，重复本文档的步骤即可。
> 使用边界（2026-09-16）：本地解析器已补齐并用一份真实导出完成结构测试；百家社网页和接口仍可能调整，若提示结构变化必须停止并复核，不能猜字段。
> 安全边界：登录令牌、原始 `账号数据.json` 均为敏感信息。不得粘贴到聊天、外传或提交到资料库；需要协助时，只在用户自己的已登录浏览器中操作，解析后优先使用不含令牌的账号档案。

---

## 一、前提条件

1. 能正常访问并**登录**《率土之滨》百家社网页：`https://stbj.163.com`
2. 本项目工具已就绪（`临时/` 目录下的解析脚本可用，Node 环境正常）

---

## 二、完整流程（四步）

### 第 1 步 · 登录目标账号

浏览器打开 `https://stbj.163.com`，登录到**要抓取的账号**。

> 确认登录成功：页面能看到你自己的昵称、头像，而不是"登录"按钮。

### 第 2 步 · 抓取账号数据

1. 按 `F12` 打开开发者工具，切到 **控制台（Console）** 标签
2. 粘贴下面这段脚本，按回车：

```js
(async () => {
  var token = '';
  try { token = JSON.parse(localStorage.getItem('LOCAL_USER_INFO')).token; } catch (e) {}
  if (!token) { try { token = JSON.parse(localStorage.getItem('LOCAL_URS_USER_INFO')).token; } catch (e) {} }
  if (!token) { console.log('❌ 没找到令牌，请确认已登录百家社'); return; }
  var r = await fetch('/api/ngsocial/Reader/HandleGameProxy', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'Authorization': token },
    body: JSON.stringify({ cmd: 'community_query_user_info', params: {} }),
    credentials: 'include'
  });
  var data = await r.json();
  var a = document.createElement('a');
  a.href = URL.createObjectURL(new Blob([JSON.stringify(data, null, 1)], { type: 'application/json' }));
  a.download = '账号数据.json'; document.body.appendChild(a); a.click(); a.remove();
  console.log('✅ 已下载 账号数据.json');
})();
```

3. 看到 `✅ 已下载 账号数据.json` 即成功（浏览器会自动下载一个文件）

### 第 3 步 · 放到项目目录

建议把下载的 `账号数据.json` 暂时放在桌面，不要直接收入项目资料库。它属于敏感原始文件。

```
D:\Desktop\账号数据.json
```

### 第 4 步 · 解析成账号档案

在项目目录先执行只读检查（不会写出账号档案）：

```powershell
$py = 'C:\Users\Administrator\.workbuddy\binaries\python\versions\3.13.12\python.exe'
& $py .\工具\配将服务\parse_account.py "D:\Desktop\账号数据.json"
```

只有在用户明确要求建立本次账号档案后，再执行：

```powershell
& $py .\工具\配将服务\parse_account.py "D:\Desktop\账号数据.json" ".\临时\account-profile.json"
```

生成的 `临时/account-profile.json` 就是配将师读取的账号档案。

---

## 三、切换账号

切换账号 = **退出当前账号 → 登录新账号 → 重新走一遍上面的四步**。

要点：

1. 第 1 步务必确认**已经登录到新账号**（看昵称/头像对不对）
2. 第 2 步脚本会自动读**当前登录账号**的令牌，不用改任何东西
3. 第 3 步覆盖旧文件后，第 4 步重新解析即可

---

## 四、多账号管理（可选）

如果要在多个账号之间来回切，建议**每个账号留一份**，避免反复抓取：

如确需多账号管理，只保留不含令牌的解析档案；原始导出用完后由用户自行决定是否删除。解析时分别指定输出名：

```bash
& $py .\工具\配将服务\parse_account.py "D:\Desktop\账号数据-大号.json" ".\临时\account-profile-大号.json"
```

配将师用哪份档案，就加载对应的 `account-profile-*.json`。

## 五、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `❌ 没找到令牌` | 没登录，或令牌存储键变了 | 确认已登录；刷新页面再试 |
| 下载的 json 里 `error_code` ≠ 0 | 令牌过期 / 接口变动 | 退出重新登录，再抓一次 |
| 武将数量为 0 或异常 | 抓取的是空数据 | 重新登录后重抓 |
| 提示 `UniSDKJSBridge` 报错 | 页面在普通浏览器打开的提示 | 无害，忽略 |

---

## 六、数据安全提醒

- `账号数据.json` 和抓取过程中涉及你的**登录令牌**，属敏感信息
- 不要外传；用完可删除原始文件，保留解析后的 `account-profile.json` 即可
- `account-profile.json` 只含武将/战法/红度等游戏数据，不含令牌，可安全留用
